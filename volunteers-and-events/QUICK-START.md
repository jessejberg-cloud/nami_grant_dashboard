# Volunteers & Events: Quick Start

Use it to plan events, fill volunteer jobs, record who came and their hours, and keep track of gifts from supporters.

## Open it

**Option A: the shared link (best for a team).**
Open the link Jesse sends you. Sign in to Claude if it asks. You and everyone else the link is shared with see the same records, and changes show up for everyone within a few seconds.

> You can only make changes if Jesse shared the link with you as an **Editor**. If the top right of the page says **View only**, ask Jesse to change your access.

**Option B: the file (no account, no internet needed).**
Double-click `Volunteers-and-Events.html` and it opens in your web browser. Everything is saved in that browser on that computer. Keep using the same computer and the same browser.

There is no Save button. Everything saves as you type. The words at the top right say where your work is saved.

## The first five minutes

1. **Add an event.** Tap **Events**, then **New event**, and type a name. Add the date, times and place when you know them.
2. **Add the jobs.** On the event, tap **Add a job**. Name it (Greeter, Setup, Food table) and enter how many people it needs. Jobs that still need people show a yellow "spots open" label.
3. **Add the people.** Under a job, type a volunteer's name and press **Enter**. Someone new is saved to your Volunteers list for you.
4. **Keep a to-do list** on the event. Type a to-do, press Enter, and tick it off when it's done.

## After an event

5. Open the event. Next to each person, tap **Came** or **Didn't come**. You can also tap **Everyone came** to mark them all at once.
   Hours fill in from the event times. Type a different number to change one person's hours.
6. **More → Volunteer hours** adds up everyone's hours for any dates. **Copy for a spreadsheet** lets you paste the table into Excel or Google Sheets.

## Supporters and gifts

7. Tap **Supporters**, then **New supporter**, then **Add a gift**. Choose money, food or goods, or time. Mark it **Promised**, then change it to **Received** when it arrives.
8. **More → Gifts** shows money received, money promised, and every gift of goods or time.

## Good to know

- **Made a mistake?** Tap **Undo** in the message at the bottom of the screen. To get back something you deleted, go to **More → Recently deleted** and tap **Bring back**.
- **Have a list of volunteers already?** Go to **Volunteers → Add many at once** and paste one person per line, like `Name, phone, email`.
- **Want to try it first?** Use **More → Settings → Add example records**. They're marked "Example", and **Remove the example records** takes them all out again.
- **Bigger text or dark colors:** **More → Settings**.
- **Back up** now and then: **More → Backup → Save a backup file**. You need this most when using the file version (Option B).
- **Don't put in:** health or diagnosis information, background-check reports, ID numbers or bank details.
